# FASE 1: VALIDACAO
## 0-3 Clientes | Janeiro-Fevereiro 2026

### Objetivo Principal
> Fechar os primeiros 3 clientes para validar:
> - O produto resolve o problema?
> - A mensagem ressoa?
> - O preco esta certo?
> - Qual canal converte melhor?

### Mentalidade da Fase 1

| Fazer | Nao Fazer |
|-------|-----------|
| Conversar muito com leads | Automatizar tudo |
| Ouvir objecoes | Ignorar feedback |
| Ajustar mensagem | Ficar preso ao script |
| Fechar manual | Esperar leads virem |
| Aprender rapido | Buscar perfeicao |
